# e-plantShopping

Paradise Nursery is a React shopping cart application for an online houseplant store.

The application allows users to:

- View the Paradise Nursery landing page
- Browse houseplants by category
- Add plants to a shopping cart
- View cart items
- Increase or decrease plant quantities
- Remove plants from the cart
- View the total number of plants and total cart cost

This project was built using React, Redux Toolkit, and Vite.
